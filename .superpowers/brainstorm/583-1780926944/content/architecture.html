四大功能模块

1

📡 连接管理

BLE扫描配对 → WiFi配置切换 → 连接状态机 (Disconnected → BLE Connected → WiFi Ready → Transfer Mode)

2

📁 文件浏览

读取相机目录树 → 缩略图加载 → 多选 → 格式标识 (RAW/JPEG/Video)

3

📤 文件传输

队列管理 → 断点续传 → 后台传输 (WorkManager) → 传输进度通知

4

📷 遥控拍摄

LiveView 实时取景 → 参数显示/调整 → 触屏对焦 → 快门释放 → 即时回传预览

关键技术决策

DI框架 Hilt (Dagger-Hilt) — Google推荐，对ViewModel集成最好
异步处理 Kotlin Coroutines + Flow — 原生支持，轻量
图片加载 Coil — Kotlin原生，轻量级，支持RAW预览扩展
后台传输 WorkManager — 保证传输任务完成，兼容Android各版本后台限制
本地存储 Room Database (传输记录) + MediaStore / SAF (照片写入系统相册)
网络通信 OkHttp (WiFi/HTTP) + Android BLE API + 自定义PTP/IP客户端
