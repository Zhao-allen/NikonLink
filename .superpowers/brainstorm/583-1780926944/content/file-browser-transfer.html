传输管理设计

Transfer Queue + WorkManager Architecture

📋 传输队列流程

1️⃣ 用户选择文件 → 加入传输队列 → Room DB持久化任务
2️⃣ WiFi连接建立 → WorkManager开始执行传输
3️⃣ 按优先级传输：先传JPEG缩略图预览 → 再传RAW/视频
4️⃣ 中断恢复：每传输完一个文件更新DB进度，断点记录已传字节
5️⃣ 完成 → 写入相册(MediaStore) → 通知栏显示 → 更新DB状态
